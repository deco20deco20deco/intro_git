# 都知事杯ODH2026 使えるデータソース総覧

作成日：20260725

---

## 0. 結論（先に3つ）

1. **東京都オープンデータAPIは78,199件あり、ユーザー登録もAPIキーも一切不要。** 公式ドキュメントに「ユーザ登録は不要で、誰でもすぐにAPIを利用することが可能です」と明記。エンドポイントに叩けば即JSONが返る。**8月のハッカソン本番で申請待ちが発生しない唯一の大規模データ源**であり、ここを起点に設計すべき。
2. **「全部あげ切る」は物理的に不可能かつ無意味。** 東京都カタログだけでデータセット10,830件、API 78,199件。CSV1本ずつ列挙しても使えないので、**使える単位（レイヤー×分野×入手難度）で構造化**した。個別データセットはカタログ検索で当てる前提。
3. **入手難度が勝敗を分ける。** 人流データなど「あれば強いが法人契約必須」のものに時間を溶かすと2日間のハッカソンは終わる。**即日使えるものだけで設計を組み、申請系は保険**にするのが正解。

## 9. 戦略上の使い方

### 掛け算の設計原則
1. **必ず3層をまたぐ**（東京都API × 国データ × 民間/OSM）。過去の都知事杯は全てこの形
2. **町丁目単位に揃える。** e-Stat小地域統計が結合キーになる。「区単位」の粒度では審査で弱い
3. **リアルタイム要素を1つ入れる。** ODPTのGTFS-RT（Protocol Buffers 47件）かGBFSが最も手軽
4. **認証不要のものだけで動くMVPを先に作る。** 申請系は後から差し込む

### 行動変容インセンティブ戦略（前回の推奨）に効くデータ
- 対象セグメントの定義：e-Stat 小地域統計（町丁目別の年齢・世帯構成）
- 行動の現状：東京都の健康・医療524件／高齢者・福祉703件から受診率・利用率系
- 移動と接点：ODPT（GTFS/GTFS-RT）＋GBFS＋OSM POI
- 効果試算の分母：東京都の行財政3,891件（予算・給付実績・事業費）
- **行政コスト削減の根拠は行財政分野に眠っている。ここを触る参加者はほぼいない**
