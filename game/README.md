# Dust Horde — ホード・サバイバー試作

TikTok広告の "Zombie Waves" と同ジャンル＝**horde survivor**（Vampire Survivors / Brotato 系）。
`horde.html` 1ファイル完結。ビルド不要、ブラウザで開けば動く。

## 遊び方

- 移動：画面をドラッグ（仮想スティック）／ `WASD` `←↑↓→`
- 攻撃：**全自動**（武器ごとに別々のクールダウンで動く）
- 一時停止：`P`

## 3層の意思決定

| 層 | 何を決める | 実装 |
| --- | --- | --- |
| **ラン中** | どこへ逃げるか、何を拾うか | `update()` |
| **レベルアップ** | 小さいステータス3択（無限に重なる） | `LEVELUPS` / `openLevelUp()` |
| **ウェーブ間ショップ** | 武器6スロットへの投資、アイテム、引き直し | `WEAPONS` `ITEMS` / `openShop()` |
| **ラン外** | 全滅で貯まるコインをタレントへ（`localStorage`） | `TALENTS` / `renderTalents()` |

## 武器と進化

基本武器5種（ボルト／シャード／ノヴァ／オービット／レイザー）。
同じ武器を買い足すとレベルが上がり、**LV5（`WMAX`）＋鍵アイテム**で別武器へ**進化**する。

| 武器 | 鍵アイテム | 進化先 |
| --- | --- | --- |
| ボルト | 照準器 | バルカン（3点バースト高速連射） |
| シャード | 拡散ドラム ★ | ストーム（全方位散弾） |
| ノヴァ | 共鳴コア ★ | シンギュラ（巨大二重衝撃波） |
| オービット | 重装軸受 ★ | ソウストーム（巨大な刃6枚） |
| レイザー | 加速レール ★ | レールガン（極太貫通ビーム） |

進化条件はショップの武器カードに常時表示される（＝**目標が見えている**のが要点）。
テーブルは `EVOLUTIONS` 配列。1行足せば進化が1つ増える。

## 数百体を軽く保つための工夫

- **空間ハッシュ**（`grid`, `CELL`）で弾・刃と敵の判定を近傍セルだけに限定
- 敵同士の押し出しは**自セル内・最大10体まで**（壁のように見えれば十分）
- 弾は1回の `stroke()` にまとめる／画面外の敵は消す
- 接触ダメージは**合計に上限**、かつ自機が敵を押しのけて抜けられる（囲まれ即死の回避）
- ヒットストップ（`hitStop`）は `dt` を0にするだけ。演出は止まり、ループは回り続ける

実測：敵130〜180体で 60fps（ヘッドレス Chromium, DPR 2）。上限は `SPAWN_CAP = 900`。

## バランスを触る場所

- `spawnRate()` … 毎秒湧く数（`3 + wave * 3.2`）
- `TYPES` … 敵のHP・速度・接触ダメージ・XP
- `WEAPONS[].base` と `wstat()` … 武器の初期性能とレベル成長
- `ITEMS` / `LEVELUPS` / `TALENTS` … 強化の中身と値段
- 経済：コインは1ドロップ2枚、`RAR_PRICE` と `priceOf()` が価格、`freeRerolls` が引き直し
