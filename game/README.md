# Dust Horde — ホード・サバイバー試作

TikTok広告の "Zombie Waves" と同ジャンル＝**horde survivor**（Vampire Survivors / Brotato 系）。
`horde.html` 1ファイル完結。ビルド不要、ブラウザで開けば動く。

## 遊び方

- 移動：画面をドラッグ（仮想スティック）／ `WASD` `←↑↓→`
- 攻撃：**全自動**（武器ごとに別々のクールダウンで動く）
- 一時停止：`P`

## 3層の意思決定

| 層 | 何を決める | 実装 |
| --- | --- | --- |
| **ラン中** | どこへ逃げるか、何を拾うか | `update()` |
| **レベルアップ** | 小さいステータス3択（無限に重なる） | `LEVELUPS` / `openLevelUp()` |
| **ウェーブ間ショップ** | 武器6スロットへの投資、アイテム、引き直し | `WEAPONS` `ITEMS` / `openShop()` |
| **ラン外** | 全滅で貯まるコインをタレントへ（`localStorage`） | `TALENTS` / `renderTalents()` |

## 武器と進化

基本武器5種（ボルト／シャード／ノヴァ／オービット／レイザー）。
同じ武器を買い足すとレベルが上がり、**LV5（`WMAX`）＋鍵アイテム**で別武器へ**進化**する。

| 武器 | 鍵アイテム | 進化先 |
| --- | --- | --- |
| ボルト | 照準器 | バルカン（3点バースト高速連射） |
| シャード | 拡散ドラム ★ | ストーム（全方位散弾） |
| ノヴァ | 共鳴コア ★ | シンギュラ（巨大二重衝撃波） |
| オービット | 重装軸受 ★ | ソウストーム（巨大な刃6枚） |
| レイザー | 加速レール ★ | レールガン（極太貫通ビーム） |

進化条件はショップの武器カードに常時表示される（＝**目標が見えている**のが要点）。
テーブルは `EVOLUTIONS` 配列。1行足せば進化が1つ増える。

## 地形と経路探索（第1段）

無限平面では「逃げる」が常に最適解になるので、**有限の部屋＋障害物**にした。

- `TILE=26px` のグリッド。`solid`（壁）と `ground`（床属性）の2枚
- **マップはランを通して1枚**（72×72マス）。ウェーブで作り直さないし、敵も消さない。
  レイアウトは `buildRoom()` がラン開始時に1回だけ生成（`stream("room", 1)`）。
  種類は **開けた広場／柱の森／十字路／回廊／円形闘技場**＋岩の散布
- 狭くなるのは**外周の崩落**（`collapseR()`）。ウェーブごとに使える半径が4%ずつ縮み、
  外に出ると継続ダメージ。マップを切り替えずに戦場だけが狭まる
- 床属性：**沼**（移動0.55倍）／**毒**（継続ダメージ）／**氷**（慣性で止まれない）／**茨**（敵にダメージ＝誘い込む）

### 経路探索はフローフィールド

A* は1体ごとに探索するので数百体では破綻する。目的地が常にプレイヤー1点なので、
**距離場を1回だけ作って全員が勾配を下る**方式にした（`rebuildFlow()`）。

- プレイヤーのマスから幅優先探索して全マスの距離を求める（壁は通行不可なので迂回距離になる）
- 敵は自分のマスの8近傍で最小の距離を見るだけ（`flowDir()`）。斜めの角抜けは禁止
- 計算量は**敵の数と無関係**。更新はプレイヤーがマスを移ったときだけ（最低でも0.5秒に1回）
- **視線が通る敵は直進、通らない敵だけ流れ場に従う**（`hasLOS()` を敵ごとに約0.2秒キャッシュ）。
  壁のない場所では従来どおり滑らかに動き、壁越しではきちんと回り込む

### 射線

- 自動攻撃は**「射線が通る最寄り」**を狙う（`nearestEnemy()` が近い順に最大10体だけ視線判定）
- 弾・敵の弾は壁で消える。レイザーは壁までで長さが切られる
- 弾は**1フレームの移動をマス幅以下に刻んで**進める。速い弾（540〜680px/s）は
  1フレームで23px進むので、26pxの壁を丸ごと飛び越えてすり抜けていた
- **範囲攻撃も壁を無視しない**：ノヴァ・爆発は対象ごとに射線判定、周回する刃は壁に埋まっている間は当たらない
- 移動は軸ごとに解決（`moveEnt()`）＝壁に当たっても滑る。詰み防止に部屋の中央は常に開けておく
- 敵同士の押し合いも `moveEnt()` 経由。座標を直接動かすと、群れの圧力で壁の中へ押し込まれる
- それでも埋まった個体（石工が壁を建てた等）は、最寄りの空きマスへ這い出す処理を通す。
  這い出している間は接触ダメージを出さない

実測：敵130体・障害物あり・DPR2 で 60fps。

## 地形に置かれるモノ（第2段）

`props` 配列にまとめてある。部屋と一緒に `placeProps()` がシードで配置する。

| モノ | 効き方 |
| --- | --- |
| **爆発ドラム** | 撃つと半径104で大爆発。群れを消し飛ばし、**ドラム同士が連鎖**し、壊せる壁も削る。自分への有効半径は62と狭くしてある（道具であって罠ではない） |
| **湧き穴**（ウェーブ4〜） | 3.2秒ごとに敵を吐く。壊せば止まる＝**群れを削るより元を断つ**判断。穴が生きている分だけ空からの湧きを減らして総量を一定に保つ |
| **制圧ポイント**（ウェーブ2〜） | 6秒立ち続けると確保。コインとHPが入り、少し後に別の場所へ湧く。**カイト一辺倒を壊す装置** |
| **護衛対象**（4の倍数ウェーブ） | 流れ場を使ってプレイヤーを追う。敵に噛まれて減り、ウェーブ終了時に生存で大きな報酬。**味方なので自分の攻撃は当たらない**（当たっていたのがバグだった）。敵を1.5秒引き剥がすと毎秒6%自己修復するので、「引き離す」が正解になる |
| **壊せる壁** | 岩の3割。弾・爆発で削れて道になる＝火力が移動性能に化ける。壊れると流れ場を作り直す |

追加した敵：

- **壊し屋**：進路の壊せる壁を削って道をこじ開ける（籠城潰し）
- **石工**：プレイヤーの近くに壁を建てて逃げ道を塞ぐ（最大3体）
- **飛行**：壁も床属性も無視して直進する（地形頼みの戦術への保険）
- 遠距離・設営系は**生存数に上限**を設ける。溜まりすぎると避けようがなくなるため

## ウェーブの切れ目は「途切れさせない」

ラウンド制（敵を全消しして部屋を作り直す）は連続性を壊すのでやめた。切れ目にあるのは：

- 落ちているXP・コインの自動回収 → ショップ（時間は止まる）
- ショップを閉じると **`supplyDrop()`**：半径230の衝撃波が群れを**押しのける**（殺さない）。
  同時にドラムの補充、湧き穴の追加、制圧ポイントの再設置、護衛の投入が起きる
- 敵・地形・落下物はすべてそのまま。プレイヤーもその場から動かない

つまりウェーブは「区切り」ではなく**補給のタイミング**として機能する。

## 自動攻撃の優先度

1. **爆発ドラム・湧き穴** — 射線が通り、かつ**近づいたときだけ**（`PROP_REACH`：ドラム170px／湧き穴205px）
2. 射線が通る最寄りの敵（武器の射程いっぱい）

モノを最優先にしないと「そこにあるのに撃てない」＝戦術として使えない。
一方で武器の射程（600px超）で判定すると遠くのドラムを勝手に消費してしまうので、
**モノだけ短い間合いを持たせている**。ドラムの自爆半径は73pxなので、170なら安全に起爆できる。

## 難易度カーブの考え方

**プレイヤーの伸びは加算、敵の伸びは乗算**にしてある。逆にすると（レベルアップを ×1.1 の
積み重ねにすると）レベル30あたりで完全な無敵になり、遊びが消える。

- レベルアップとアイテムは `dmgAdd` / `rateAdd` / `areaAdd` / `moveAdd` に**加算**で溜まる
- 連射倍率は3倍で頭打ち、移動速度は1.8倍で頭打ち、クリ率は60%で頭打ち
- 武器には**発射間隔の下限**がある（`RATE_FLOOR`：直射0.10／ノヴァ1.0／レイザー0.6／刃0.12秒）。
  これが無いと連射を積むだけで毎フレーム発射になり、画面が爆発で埋まって何も見えなくなる
- 茨は**敵の最大HPの4%／0.5秒**。固定値でウェーブ倍率を掛けると、ただの最強床になる

敵側は乗算で伸ばす：

| 項目 | 式 |
| --- | --- |
| 敵HP | `1.31^(wave-1)` |
| 敵の接触ダメージ | `1.13^(wave-1)` |
| 接触ダメージの上限 | `16 × 1.16^(wave-1)` |
| 敵の速度 | `1 + 0.05×(wave-1)`（1.9倍で頭打ち＝終盤は逃げ切れない） |
| ボスHP | `1.33^(wave-1)`、ウェーブ7以降は毎ウェーブ出現 |

さらに**火力では消せない圧力**を別に用意する（DPSが伸びても効き続ける）：

- **スピッター**：間合いを取って弾を撃つ。立ち止まると当たる＝動く理由
- **ボマー**：死ぬと爆発。群れに突っ込むと連鎖して自分も巻き込む
- **ブルート**：`armor 0.5` で**弾のダメージ半減**。ノヴァ／オービット／レイザーは通る＝AoEを取る理由
- **ボスの弾幕**：4.2秒ごとに全方位12発。避けるしかない

実測（自動プレイ・平均的なビルド）：ウェーブ3〜7でHPが180前後を上下し、8〜9で崩れる。

## 共有カードとデイリー

- 全滅すると **1080×1350 のPNG** をその場で生成（到達ウェーブ・時間・キル・最終ビルド・シード）。
  `navigator.share` → 画像クリップボード → テキストの順にフォールバックする
- **シード固定デイリー**：`stream(seed, ラベル)` で乱数を用途ごとに分離しているので、
  ウェーブNの湧きも抽選も全員同じ。引き直し回数が違っても同じ品揃えが出る
  （`stream("shop", wave, rerolls)`）。ベスト記録は `localStorage` に残る
- フリーランにも6桁シードが振られてカードに載る。タイトル画面の入力欄に打ち込むと
  **同じ地形・同じ湧き・同じ品揃えで最初から**遊べる（進行の再開ではない）
- 恒久強化は**1段階ずつ取り消せる**（払った額の半分が戻る）。押し間違いの救済

## 数百体を軽く保つための工夫

- **空間ハッシュ**（`grid`, `CELL`）で弾・刃と敵の判定を近傍セルだけに限定
- 敵同士の押し出しは**自セル内・最大10体まで**（壁のように見えれば十分）
- 弾は1回の `stroke()` にまとめる／画面外の敵は消す
- 接触ダメージは**合計に上限**、かつ自機が敵を押しのけて抜けられる（囲まれ即死の回避）
- ヒットストップ（`hitStop`）は `dt` を0にするだけ。演出は止まり、ループは回り続ける

実測：敵130〜180体で 60fps（ヘッドレス Chromium, DPR 2）。上限は `SPAWN_CAP = 900`。

## バランスを触る場所

- `spawnRate()` … 毎秒湧く数（`3 + wave * 3.2`）
- `TYPES` … 敵のHP・速度・接触ダメージ・XP
- `WEAPONS[].base` と `wstat()` … 武器の初期性能とレベル成長
- `ITEMS` / `LEVELUPS` / `TALENTS` … 強化の中身と値段
- 経済：コインは1ドロップ2枚、`RAR_PRICE` と `priceOf()` が価格（物価は毎ウェーブ+22%）
- 引き直しは**補給1回につき3回まで**（`rerollsLeft`、博打タレントで+1）。費用は 8→15→22 と上がる
- **買えるのは1回の補給につき3つまで**（`BUYS_PER_SHOP`）。4択から3つ＝「何を切るか」が残る
- **同じアイテムは5個まで**（`ITEM_MAX`）。上限なしだと同じ物を24個積めてしまい、
  加算にしても成長が壊れる（実際のプレイで 過給機×24／巨人の心臓×24 が出た）

## ラン外の構造（クリア条件・難易度階層・キャラ・拠点）

- **ウェーブ20を凌げばクリア**（`WIN_WAVE`）。勝利画面から「続ける」で無限モードへ（`endless`）
- **難易度階層 DANGER 0〜5**（`DANGERS` / `dangerMods()`）。効果は**累積**し、クリアすると次が解放される
  （エリート前倒し → 物価+35% → 敵速度+15% → 引き直し1回 → 回復半減＆敵HP+25%）
- **キャラクター5人**（`CHARS`）。初期武器・利点・**縛り**が違う。斥候以外は実績で解放
  （狙撃手＝射程+50%/移動−25%、走り屋＝移動+40%/HP半分、整備士＝スロット4、狂人＝クリ+30%/回復不可）
- **生存者の救出**：檻に近づいて2.5秒で解放 → 追従 → **ウェーブを越えれば拠点に加入**。
  職業（医者・技師・農家・射手・無線技師）ごとに次のランを恒久的に強くする（職業ごと6人まで有効）
- **武器の役割分化**：直射・範囲・貫通に加えて、**地雷**（設置）／**ドローン**（随伴）／
  **冷却塔**（鈍足）／**収束装置**（引き寄せ）。引き寄せ＋範囲のような**噛み合わせ**が生まれる
- 進化も4つ追加（クラスター／ガンシップ／ブリザード／ブラックホール）
