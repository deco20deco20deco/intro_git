# Dust Horde — ホード・サバイバー試作

動画（TikTok広告の "Zombie Waves"）と同ジャンル＝**horde survivor**（Vampire Survivors 系）の最小プロトタイプ。
`horde.html` 1ファイル完結。ビルド不要、ブラウザで開けば動く。

## 遊び方

- 移動：画面をドラッグ（仮想スティック）／ `WASD` `←↑↓→`
- 攻撃：**全自動**（最寄りの敵を狙う）
- 一時停止：`P`

## 中身（このジャンルの骨格）

| ループ | 実装箇所 |
| --- | --- |
| 敵が自機へ直進 | `update()` の enemies ループ |
| 一定間隔で最寄り敵へ自動発射 | `fire()` |
| 撃破 → XP／コイン ドロップ | `kill()` |
| 拾う → レベルアップ → 3択強化 | `gainXp()` / `openLevelUp()` |
| 30秒ごとにウェーブ、偶数ウェーブでボス | `nextWave()` / `spawnBoss()` |

強化は `upgrades` 配列にオブジェクトを1つ足すだけで増える。

## 数百体を軽く保つための工夫

- **空間ハッシュ**（`grid`, `CELL`）で弾と敵の判定を近傍セルだけに限定
- 敵同士の押し出しは**自セル内・最大10体まで**（壁のように見えれば十分）
- 弾は1本の `Path2D` 相当でまとめて `stroke()`（描画コール削減）
- 画面から大きく離れた敵は消す（`despawn`）
- 接触ダメージは**合計に上限**（囲まれても即死しない／壁を押しのけて抜けられる）

実測：敵180体前後で 60fps（ヘッドレス Chromium, DPR 2）。上限は `SPAWN_CAP = 900`。

## 主要パラメータ

`horde.html` 冒頭の tuning ブロックと `TYPES` / `upgrades` を触ればバランスは全部変わる。

- `WAVE_LEN` … 1ウェーブの秒数
- `spawnRate()` … 毎秒湧く数（`3 + wave * 3.2`）
- `TYPES` … 敵の HP・速度・接触ダメージ・XP
- `P` の初期値 … 攻撃力 `dmg`、連射 `rate`、弾速 `bspd`、回収範囲 `magnet`

## ここから伸ばすなら

1. **メタ進行**：コインを実行間で持ち越して恒久強化（現状は集めるだけ）
2. **武器の種類**：`fire()` を武器リスト化して、ノヴァのように別挙動を追加
3. **見た目を3Dへ**：遊びが固まってから Unity（URP・見下ろし）へ移植。
   ロジックはほぼそのまま C# に置き換わる。大量描画は GPU Instancing / DOTS。
4. **モバイル実機**：現状でも縦持ちで動く。PWA 化 or Capacitor でアプリ化。
