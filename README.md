### 設計原則（データ面）

1. 必ず3層をまたぐ（東京都 × 国 × 民間/OSM）。単一カタログ完結は部門賞止まり
2. 粒度は町丁目に揃える（e-Stat小地域統計を結合キーに）
3. リアルタイム要素を1つ入れる（GTFS-RT または GBFS）
4. 認証不要のデータだけで動くMVPを先に作り、申請系は後から差し込む
